# Neon Flow

Every project by Caleb Juarez (Neon Forger), each with its own page.
Live at https://neon-forger.github.io/NeonFlow/

## Adding a project
- Easiest: open **Submit a project** on the site (a GitHub form), then add it to `projects.js`.
- Or edit `projects.js` directly: copy an entry, give it a new `id`, and put its pictures in `assets/<id>/`.
  The home page and the project page (`project.html?p=<id>`) are built from that list automatically.
